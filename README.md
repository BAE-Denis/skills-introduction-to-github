# skills-introduction-to-github

Exercise: Introduction to GitHub

本项目是一个用于练习 GitHub 基础操作的示例仓库。

## 关于本仓库

这是一个 GitHub 入门练习仓库,用来熟悉 Issue、分支、Pull Request 等核心协作流程。

## 如何参与

1. **创建 Issue**:发现问题时,通过 Issues 页新建一个 Issue,描述问题背景与复现步骤。
2. **创建分支**:从 `main` 分支切出一个新分支进行改动。
3. **提交 Pull Request**:改动完成后提交 PR,并在描述中关联对应 Issue(例如 `Closes #2`)。
4. **讨论与合并**:在 PR 中进行代码评审,确认无误后合并到 `main`。
